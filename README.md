# BottleGuard v1.0

**BottleGuard** is a Python-based Quality Inspection Simulator designed to simulate a basic bottle quality control process through a terminal interface.

## Project Overview

This project simulates a simple industrial bottle inspection system. It checks several bottle parameters and determines whether a bottle meets the specified quality standards.

## Features

- Bottle presence detection simulation
- Bottle cap detection simulation
- Bottle height inspection
- Bottle width inspection
- Automatic inspection result: ACCEPTED or REJECTED
- Simple terminal-based menu

## Inspection Parameters

| Parameter | Quality Standard |
|---|---|
| Bottle Presence | Must be detected |
| Cap Detection | Must be detected |
| Bottle Height | 10–20 cm |
| Bottle Width | Minimum 5 cm |

## Technologies

- Python
- Basic Python programming concepts
- Conditional statements (`if`, `elif`, `else`)
- User input and type conversion

## How to Run

1. Make sure Python is installed.
2. Download or clone this repository.
3. Open the project folder in your terminal.
4. Run the following command:

```bash
python bottleguard.py
```
